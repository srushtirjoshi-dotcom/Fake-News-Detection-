# 🧠 Fake News Detection using AI

A web-based application that analyzes news content and classifies it as **Real or Fake** using AI.
This project also includes an interactive quiz to improve user awareness about misinformation.

---

## 🚀 Features

* 🔍 **News Analysis** – Input any news and get instant classification (Real/Fake)
* 🤖 **AI Integration** – Uses API-based AI model for prediction
* 🎯 **Interactive Quiz** – Users can test their knowledge by identifying real vs fake news
* 📊 **Instant Feedback** – Quiz highlights correct (🟢) and incorrect (🔴) answers
* 💻 **Clean UI/UX** – Simple, responsive, and user-friendly interface

## ⚙️ How to Run

1. Install dependencies:

```bash
npm install
```

2. Start the server:

```bash
node server.js
```

3. Open `index.html` in your browser.

---
## 🔐 Environment Setup

Create a `.env` file in the root directory and add:

API_KEY=your_api_key_here  
PORT=3000

(Note: API key will be provided separately)
